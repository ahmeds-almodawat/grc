# Gate 13S-R fingerprint method inventory

The obsolete expectation and the hosted result were generated by different pipelines. Gate 13B-R3 fingerprinted synthetic source/baseline SQL, while Gate 13S fingerprinted a linked Supabase CLI schema dump. The paths differed in identifier quoting, `CREATE OR REPLACE` rewrites, default privileges/ACL statements, and PostgreSQL deparse roundtrip state.

Gate 13S-R uses one pipeline for both catalogs: schema-only dump, one PostgreSQL 17.6 parse/dump replay, exact exclusion of Supabase-managed `supabase_admin` defaults, semantic stable-identity records, deterministic sorting, and SHA-256. Application ACLs, owners, RLS, policies, function definitions/search paths/security state, constraints, indexes and lineage objects remain bound.
