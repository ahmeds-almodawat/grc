# Gate 13S-R canonical fingerprint contract

The canonical contract binds 26,257 schema-only semantic records. It includes object ownership, columns/defaults, function identities and bodies, SECURITY DEFINER and search paths, RLS/FORCE RLS, complete policy definitions, grants/revokes, constraints, index predicates/expressions, triggers, views, comments and the 186–187 lineage/attestation objects.

Only formatting, deterministic order, OID-free stable names, PostgreSQL dump keyword rewrites, placeholder-view mechanics and Supabase-managed `supabase_admin` defaults are normalized. Unresolved numeric roles and conflicting stable identities fail closed.
