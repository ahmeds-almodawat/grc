# Gate 6 evidence authority registry

Patch 83U evidence is point-in-time evidence. Run 006, Run 007, and Run 008 contracts and freezes remain immutable and are validated against the schema and inventory active when each artifact was captured. They are not required to equal the current harness.

Run 009 is the current authoritative hosted-reset proof contract and freeze. A superseded or failed-attempt artifact remains discoverable and hash-validated, but it cannot be selected as current release authority.

The companion JSON registry records the deterministic path, capture date, run, status, successor, immutable SHA-256, and authority classification. Gate 6 did not rewrite any registered artifact.
