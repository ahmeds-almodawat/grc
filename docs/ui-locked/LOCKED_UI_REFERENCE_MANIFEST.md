# GRC Locked UI Reference Manifest

Purpose: authoritative visual references for the GRC full-platform UI implementation.

## Rules
- These images are **locked visual specifications**, not inspiration.
- Match colors, spacing, proportions, surfaces, borders, typography hierarchy, status colors, light/dark treatment, desktop structure and ~390px mobile behavior as closely as technically possible.
- Mock/sample data inside generated images is illustrative; real platform data and governed terminology remain authoritative.
- Obvious image-generation text typos are not authoritative.
- Existing business logic, RBAC, workflow semantics, security, schema and API behavior outrank visual convenience.
- **The locked Home/Executive Dashboard shell is the master shell and overrides sidebar/header inconsistencies in later images.**
