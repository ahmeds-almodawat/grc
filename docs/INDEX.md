# GRC Control Center - Documentation Index

Welcome to the Al Modawat GRC Control Center documentation.
This repository contains the governance, risk, and compliance management platform.

## Structure
- `/docs/architecture`: System architecture and design documentation.
- `/docs/runbooks`: Operational runbooks and emergency procedures.
- `/docs/release-evidence`: Information on where release proofs are stored.
- `/release`: Contains generated validation proofs, schema audits, and deployment reports for every patch.
- `/scripts`: Contains NodeJS tools used in CI/CD, validation testing, and release auditing.
